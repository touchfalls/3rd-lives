First public release of Life SMP for Minecraft 1.21.1.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.0.0.jar` | Paper and Paper forks such as Purpur (put into `plugins/`) |
| `lifesmp-fabric-1.0.0.jar` | Fabric server with Fabric API (put into `mods/`) |

Requires Java 21. Server side only; players use a vanilla client.

## Features

- Three lives per player. Name color in chat and TAB shows the remaining lives: green, gold, red.
- Losing the last life bans the player for 24 hours (`ban-hours`). On the first login after the ban the player returns with full lives.
- Players on their last life cannot be attacked unless they attacked first (30-second retaliation window). Two red players cannot fight each other.
- Lives regenerate after 10 hours of online time (`regen-hours-per-life`). The timer pauses while the player is AFK.
- `/life gift <player>` and `/life accept`: give one of your lives to another player. The donor regenerates the next life faster (2.5 hours by default).
- Arenas where everyone can fight and deaths cost no lives (`/life arena`), and a timed global PvP event (`/life event pvp-override`).
- Banned players are shown as gray `[DEAD]` entries at the bottom of the TAB list.
- Admin commands: `/life pardon`, `/life reset`, `/life set`, `/life reload`. They also work for offline players.
- Messages in English, Russian, French, Italian and Spanish (`language` in the config). Every message can be overridden with MiniMessage.
- SQLite storage with automatic schema migrations; no database server required.

## Configuration

- Paper: `plugins/LifeSMP/config.yml`
- Fabric: `config/lifesmp/config.json`

Apply changes with `/life reload`. The full list of options, commands and permissions is in the [README](https://github.com/touchfalls/3rd-lives#readme).

## Known limitations

- Only Minecraft 1.21.1 is supported.
- Testing on Paper forks other than Paper itself has been limited.
- French, Italian and Spanish translations have not yet been reviewed by native speakers.

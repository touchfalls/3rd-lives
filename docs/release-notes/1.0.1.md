Bug fix release for Life SMP on Minecraft 1.21.1. Existing worlds and databases are upgraded automatically; back up `lifesmp.db` before updating.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.0.1.jar` | Paper and Paper forks such as Purpur (put into `plugins/`) |
| `lifesmp-fabric-1.0.1.jar` | Fabric server with Fabric API (put into `mods/`) |

Requires Java 21. Server side only.

## Fixed

- AFK pausing now works on Fabric, and on Paper for players who never move after joining. Before, those players kept regenerating lives while away.
- Fabric: joining, kicking banned players, name colors and messages now run on the server thread. This removes a possible crash or odd behavior when many players join at once.
- A death is saved to the database immediately. Before, a server crash within 5 minutes of a death gave the life back.
- `/life arena create` no longer replaces an existing arena with the same name; it tells you the arena already exists.
- Player data is released from memory after the player leaves, so memory no longer grows on long-running servers.
- A death no longer waits for the database on the server thread when the player's data is missing from memory.
- `/life set` now also clears the player's gray `[DEAD]` TAB entry and saves at once.
- A life gift is saved for both players together, so a crash cannot keep only half of the transfer.

## Changed

- The "you were pardoned" message for players pardoned while offline is stored in the database and is no longer lost on restart. The database schema moves to version 4 on the first start.
- New message `arena.already-exists` in all five languages.

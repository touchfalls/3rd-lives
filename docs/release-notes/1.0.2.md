Bug fix release for Life SMP on Minecraft 1.21.1. No database change: update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.0.2.jar` | Paper and Paper forks such as Purpur (put into `plugins/`) |
| `lifesmp-fabric-1.0.2.jar` | Fabric server with Fabric API (put into `mods/`) |

Requires Java 21. Server side only.

## Fixed

- The gray `[DEAD]` TAB entry of a banned player no longer disappears for players who are online. When a player disconnects, the game removes the TAB entry with the same UUID for everyone, and that also removed the fake dead entry. The entry is now shown half a second after the kick, and only if the player is still banned then.
- Switching `dead-tab.enabled` on with `/life reload` now shows the dead entries to players who are already online.
- A death still costs a life when the player's data is not in memory, for example after a plugin reload. Before, such a death was skipped.
- `/life set`, `/life pardon` and `/life reset` on Paper no longer change the scoreboard from the database thread. Fabric no longer sends the name update twice.

## Please test

The `[DEAD]` fix could not be tried on a real server before release. With two players online, let one lose the last life: the other player should see the gray `[DEAD]` entry at the bottom of TAB, and so should a player who joins later. If the entry still disappears, please open an issue with the platform and the steps.

Adds Minecraft 26.2 support, fixes `/life accept`, and lets you turn AFK detection off. No database change: update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.1.0.jar` | Paper and Paper forks such as Purpur, 1.21.1 and 26.2 (put into `plugins/`) |
| `lifesmp-fabric-1.21.1-1.1.0.jar` | Fabric server 1.21.1 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.2-1.1.0.jar` | Fabric server 26.2 with Fabric API (put into `mods/`) |

Java 21 for Minecraft 1.21.1, Java 25 for 26.2. Fabric 26.2 needs Fabric Loader 0.18.4 or newer. Server side only.

## Added

- Minecraft 26.2 support. The Paper jar is the same for 1.21.1 and 26.2. Fabric has one jar per Minecraft version.
- `afk-minutes: -1` turns AFK detection off, so the regeneration timer also runs for players who stand still.

## Fixed

- `/life accept` now accepts a gift. Before, every accept answered that the request had expired. This affected Paper and Fabric in all earlier versions.

## Changed

- The Fabric jar for 1.21.1 is now named `lifesmp-fabric-1.21.1-<version>.jar`.

## Please test

On 26.2 the plugin and the mod start and load without errors on Paper 26.2 and Fabric 26.2, but deaths, bans and the `[DEAD]` TAB entry have not been tried with players there yet. If something breaks, please open an issue with the platform, the Minecraft version and the steps.

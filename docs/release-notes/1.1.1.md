Bug fix release: players no longer vanish for other players. No database change: update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.1.1.jar` | Paper and Paper forks such as Purpur, 1.21.1 and 26.2 (put into `plugins/`) |
| `lifesmp-fabric-1.21.1-1.1.1.jar` | Fabric server 1.21.1 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.2-1.1.1.jar` | Fabric server 26.2 with Fabric API (put into `mods/`) |

Java 21 for Minecraft 1.21.1, Java 25 for 26.2. Fabric 26.2 needs Fabric Loader 0.18.4 or newer. Server side only.

## Fixed

- Players were sometimes invisible to other players although they were online. Life SMP sent the "remove from TAB" packet for the UUID of a player who was online, and clients stop showing a player who has no TAB entry. This happened after `/life set` or `/life reset` on an online player, and when a player came back after a death ban. The packet is now sent only for real dead entries and never for a player who is online. Affects Paper and Fabric.

## Please test

Run `/life set <online player> 3` and `/life reset <online player>`, and let a banned player return after the ban. Other players should keep seeing them, including after the player teleports or changes dimension. A player who is already invisible becomes visible again after rejoining. If it still happens, other plugins that send TAB packets (vanish, TAB, anti-cheat) may be the cause; please open an issue with the platform and the steps.

Adds Minecraft 26.3 support (Paper and Fabric). No database change: update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.1.2.jar` | Paper and Paper forks such as Purpur, 1.21.1, 26.2 and 26.3 (put into `plugins/`) |
| `lifesmp-fabric-1.21.1-1.1.2.jar` | Fabric server 1.21.1 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.3-1.1.2.jar` | Fabric server 26.3 with Fabric API (put into `mods/`) |

Java 21 for Minecraft 1.21.1, Java 25 for 26.3. Fabric 26.3 needs Fabric Loader 0.18.4 or newer. Server side only.

## Changed

- The Fabric 26.x jar is built for Minecraft 26.3 (Fabric API 0.165.0+26.3) instead of 26.2. Fabric 26.2 servers should stay on 1.1.1. The Paper jar is the same for 1.21.1, 26.2 and 26.3.

## Please test

The plugin and the mod build, pass their tests and start without errors on Paper 26.3 and Fabric 26.3 (migrations V1-V4 run), but deaths, bans and the `[DEAD]` TAB entry have not been tried with players on 26.3. Please report problems with the platform and the steps.

Brings back the Fabric jar for Minecraft 26.2. Every release now has a Paper jar for 1.21.1, 26.2 and 26.3 and one Fabric jar for each of these versions. No code or database change: update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.1.3.jar` | Paper and Paper forks such as Purpur, 1.21.1, 26.2 and 26.3 (put into `plugins/`) |
| `lifesmp-fabric-1.21.1-1.1.3.jar` | Fabric server 1.21.1 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.2-1.1.3.jar` | Fabric server 26.2 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.3-1.1.3.jar` | Fabric server 26.3 with Fabric API (put into `mods/`) |

Java 21 for Minecraft 1.21.1, Java 25 for 26.2 and 26.3. Fabric 26.2 and 26.3 need Fabric Loader 0.18.4 or newer. Server side only.

## Added

- A Fabric jar for Minecraft 26.2 again. 1.1.2 had only a 26.3 jar for Fabric 26.x. Everything from 1.1.2 is included: 26.3 support and the correct name color in join and leave messages on Fabric.

`/life` now shows how many lives you have spent. The database gets a new column on the first start (migration V5): update by replacing the jar.

## Downloads

| File | Platform |
|---|---|
| `lifesmp-paper-1.2.0.jar` | Paper and Paper forks such as Purpur, 1.21.1, 26.2 and 26.3 (put into `plugins/`) |
| `lifesmp-fabric-1.21.1-1.2.0.jar` | Fabric server 1.21.1 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.2-1.2.0.jar` | Fabric server 26.2 with Fabric API (put into `mods/`) |
| `lifesmp-fabric-26.3-1.2.0.jar` | Fabric server 26.3 with Fabric API (put into `mods/`) |

Java 21 for Minecraft 1.21.1, Java 25 for 26.2 and 26.3. Fabric 26.2 and 26.3 need Fabric Loader 0.18.4 or newer. Server side only.

## Added

- `/life` has a new line with the total number of lives the player has lost to deaths. Arena deaths do not count. Deaths before this version were never recorded, so everyone starts at 0.
- Database schema version 5: the `lives_spent` column in `players`.
